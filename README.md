# Responsible AI Course: Algorithmic Fairness

Course materials (website and slides) for the Algorithmic Fairness session of the Responsible AI Course, built with [Quarto](https://quarto.org).

Hosted version at [https://simson.io/responsible-ai-course-fairness/](https://simson.io/responsible-ai-course-fairness/).

## Build

```sh
quarto render                                   # website
quarto render --profile slides --to revealjs    # slides
```

Pushes to `main` are deployed to GitHub Pages automatically.
